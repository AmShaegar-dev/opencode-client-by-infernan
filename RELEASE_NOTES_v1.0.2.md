# OpenCode Client by inFernan — v1.0.2

Исправление клавиатуры при вводе паролей.

## Что нового

- **Клавиатура больше не перекрывает поля ввода.** Экран сдвигается над
  клавиатурой, а прокрутка автоматически подводит активное поле — пароль SSH,
  пароль ключа и пароль API OpenCode всегда видны целиком.
- Пароль API при установке сервера теперь скрыт точками, как и остальные
  пароли.
- Остальные изменения v1.0.1 сохранены: живой SSE-поток ответа, размышления в
  реальном времени и вложения через `file://` для загруженных файлов.

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.2.apk`.
2. Разрешите установку из этого источника.
3. Обновление установится поверх v1.0.0 / v1.0.1.
