# OpenCode Client by inFernan — v1.0.9

Готовая настройка сервера для Windows, понятные цвета серверов и шифрованный
кэш чатов на телефоне.

## Что нового

- **Файл `opencode-lan.bat` прямо из инструкции.** В разделе «Инструкция»
  появилась кнопка «Скачать opencode-lan.bat». Запустите файл на компьютере
  двойным щелчком: он сам запросит права администратора, найдёт службу
  OpenCode Desktop, задаст пароль, разрешит подключения из локальной сети,
  добавит правило брандмауэра, перезапустит службу и покажет готовые адреса,
  логин и пароль для телефона.
  - Если Desktop не установлен, скрипт попробует найти команду `opencode` и
    запустить `opencode serve --hostname 0.0.0.0` в отдельном окне.
  - Пароль по умолчанию — `AwgPass12345`; скрипт печатает его и все адреса
    компьютера (Wi-Fi и AWG).
- **Цвет полоски сервера показывает тип подключения**, а не случайный цвет
  профиля:
  - 🟠 оранжевый — открытый веб (внешний адрес);
  - 🔵 голубой — SSH-туннель;
  - 🟣 фиолетовый — локальная сеть или AWG;
  - 🔴 красный — сервер недоступен.
  Над списком добавлена компактная легенда, чтобы цвета читались без догадок.
- **Шифрованный кэш чатов на телефоне.** Список сессий и история сообщений
  сохраняются локально и показываются сразу при открытии, а затем тихо
  обновляются с сервера. Большие чаты больше не встречают пустым экраном.
  - Данные шифруются AES/GCM ключом из Android Keystore и лежат во внутренней
    памяти приложения — скопировать файлы на другое устройство и прочитать их
    нельзя.
  - Кэш ограничен 8 МБ и 40 последними чатами, старые записи удаляются
    автоматически.
  - Если сервер недоступен, сохранённая история остаётся на экране вместе с
    кнопкой «Обновить».

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.9.apk`.
2. Разрешите установку из этого источника.
3. Обновление установится поверх v1.0.0 – v1.0.8.
