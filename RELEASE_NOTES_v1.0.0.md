# OpenCode Client by inFernan — v1.0.0

Первый публичный релиз Android-клиента для OpenCode V2.

## Что внутри

- SSH-туннель и прямое HTTPS-подключение.
- Установка OpenCode на сервер по SSH.
- Чаты, вложения, серверная загрузка файлов до 200 МБ.
- Провайдеры, API-ключи и OAuth/OpenCode Go.
- Включение и выключение моделей, избранное.
- Уровни размышлений и варианты моделей.
- Команды, агенты, diff изменённых файлов.
- Свободное место на диске и очистка кэша.
- Лимиты OpenCode Go и бюджеты.
- Проверка обновлений из GitHub раз в сутки.
- Вход по SSH-ключу и пиннинг HTTPS-сертификата.
- Защита от внешнего HTTP без явного разрешения.

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.0.apk`.
2. Разрешите установку из этого источника.
3. Откройте приложение и добавьте сервер.
