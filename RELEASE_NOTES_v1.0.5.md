# OpenCode Client by inFernan — v1.0.5

Инструкция по подключению прямо в приложении.

## Что нового

- **Новый экран «Инструкция».** Пошагово объясняет, как запустить OpenCode
  на компьютере, открыть его через AWG или локальную сеть и подключить
  телефон. Открывается из **Настроек** и из редактора сервера.
- **Команды можно копировать одним нажатием.** В инструкции есть готовые
  команды для PowerShell: запуск сервера, поиск встроенного CLI Desktop,
  настройка службы и правило брандмауэра.
- **Раздел про вкладки и сессии.** Объясняет, что вкладки Desktop — это
  открытые сессии, а на телефоне те же чаты находятся в разделе «Чаты».
  Можно продолжать работу с того же места, создавать новые чаты и держать
  Desktop и телефон открытыми одновременно.
- В редакторе сервера инструкция открывается диалогом и **не сбрасывает
  заполненные поля**.
- Пресет «Локальная сеть / AWG», проверка подключения и обновления через
  `update.json` сохранены.

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.5.apk`.
2. Разрешите установку из этого источника.
3. Обновление установится поверх v1.0.0 – v1.0.4.
