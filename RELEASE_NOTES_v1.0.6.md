# OpenCode Client by inFernan — v1.0.6

Скрытые размышления и обновлённая инструкция для OpenCode Desktop.

## Что нового

- **Размышления модели по умолчанию скрыты.** В ответе видна только строка
  «Размышления (N) ▾». Нажмите на неё, чтобы раскрыть текст, и ещё раз —
  чтобы скрыть. Во время генерации размышления больше не раскрываются сами.
- **Инструкция обновлена под реальный OpenCode Desktop.** Указан настоящий путь
  к встроенному CLI: `%APPDATA%\ai.opencode.desktop\cli\...`, команды
  `service set password`, `service set hostname 0.0.0.0`, `service restart`
  и `service status`.
- **Добавлена проверка, что сервер слушает сеть.** `Get-NetTCPConnection`
  должен показывать `0.0.0.0`, а не `127.0.0.1`.
- **Понятнее с адресами.** В телефон вводится IP компьютера, а не `0.0.0.0`;
  отдельно объяснено, что `172.16.17.35/32` в `AllowedIPs` может быть адресом
  телефона, а не ПК.
- **Раздел «Не удалось загрузить».** Проверка API с ПК через
  `Invoke-WebRequest`, разбор 401/таймаута, неверного порта и старого профиля.
- **Как закрыть порты обратно.** Возврат службы Desktop на `127.0.0.1`,
  удаление правила брандмауэра, остановка отдельного `opencode serve` и
  проверка, что порт больше не слушается.

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.6.apk`.
2. Разрешите установку из этого источника.
3. Обновление установится поверх v1.0.0 – v1.0.5.
