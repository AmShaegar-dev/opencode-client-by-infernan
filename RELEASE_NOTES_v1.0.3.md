# OpenCode Client by inFernan — v1.0.3

Подключение через локальную сеть и AmneziaWG.

## Что нового

- **Пресет «Локальная сеть / AWG».** В редакторе сервера при выборе «Прямой
  URL» появился готовый режим для работы через AmneziaWG: адрес
  `http://10.8.0.3:4096`, подсказки по настройке и команда запуска OpenCode
  на компьютере.
- **Проверка подключения без сохранения.** Кнопка «Проверить подключение»
  сразу проверяет URL и пароль API, показывает версию OpenCode или понятную
  ошибку — сервер можно протестировать до добавления.
- **Справка по AWG.** Отдельный диалог объясняет порядок действий: включить
  AmneziaWG на телефоне, запустить `opencode serve --hostname 0.0.0.0
  --port 4096` на ПК и указать адрес компьютера в туннеле.
- Приложение по-прежнему не поднимает VPN само: AmneziaWG остаётся отдельным
  приложением на телефоне, а клиент подключается к OpenCode по обычному URL.

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.3.apk`.
2. Разрешите установку из этого источника.
3. Обновление установится поверх v1.0.0 / v1.0.1 / v1.0.2.
