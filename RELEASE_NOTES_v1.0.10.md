# OpenCode Client by inFernan — v1.0.10

Файлы из ответа модели теперь видно и можно открыть в чате и скачать на телефон.

## Что нового

- **Карточки файлов прямо в ответе.** Если модель создала файл или сослалась на
  него, под текстом появляется карточка: имя, путь на сервере, кнопка
  «Открыть» и кнопка скачивания. Пути берутся из текста ответа (в том числе
  из обратных кавычек) и из инструментов записи `write`, `edit`, `patch` и
  аналогичных.
- **Предпросмотр без скачивания.** «Открыть» показывает содержимое прямо в
  приложении:
  - текстовые файлы (`md`, `json`, `kt`, `ps1`, `log` и другие) — моноширинным
    текстом с прокруткой;
  - изображения (`png`, `jpg`, `jpeg`, `gif`, `webp`) — картинкой;
  - остальные файлы — сообщение, что предпросмотр недоступен, и кнопка
    «Скачать».
- **Скачивание на телефон из чата.** Кнопка скачивания сохраняет файл через
  системный диалог (можно выбрать папку «Загрузки»), поток идёт напрямую с
  сервера — большие файлы не загружаются в память целиком.
- **Загруженные на сервер файлы тоже стали карточками.** Вместо строки
  «Файл на сервере: …» в сообщении теперь карточка с теми же кнопками
  «Открыть» и «Скачать».
- Файлы читаются через `GET /api/fs/read` с каталогом проекта из сессии,
  поэтому работают и относительные пути, и полные пути Windows/Unix.

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.10.apk`.
2. Разрешите установку из этого источника.
3. Обновление установится поверх v1.0.0 – v1.0.9.
