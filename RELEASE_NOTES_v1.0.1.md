# OpenCode Client by inFernan — v1.0.1

Обновление с живым потоком ответа и исправлением вложений.

## Что нового

- **SSE-поток**: текст ответа, размышления и вызовы инструментов появляются
  по мере генерации, а не раз в секунду.
- Размышления автоматически раскрываются, пока модель думает.
- Резервный polling сохранён на случай обрыва SSE.
- Кнопка **«Обновить»** прямо во время ответа.
- Долгое размышление больше не считается зависанием: учитывается изменение
  reasoning, тайм-ауты увеличены.
- Файлы, которые не проходят как обычное вложение (например, `.docx`),
  загружаются на сервер и прикрепляются к сообщению через `file://`.
- Файлы больше 20 МБ по-прежнему передаются путём на сервере — это ограничение
  OpenCode на размер вложения.
- Заголовок «OpenCode Client by inFernan».

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.1.apk`.
2. Разрешите установку из этого источника.
3. Обновление установится поверх v1.0.0.
