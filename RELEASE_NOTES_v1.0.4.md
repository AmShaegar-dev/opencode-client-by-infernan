# OpenCode Client by inFernan — v1.0.4

Проверка обновлений работает без лимитов GitHub API.

## Что нового

- **Исправлена ошибка «GitHub ответил 403».** Проверка обновлений больше не
  зависит от GitHub API: приложение читает небольшой `update.json` из релиза
  или из ветки `main`. Это обходит лимит 60 запросов в час, который особенно
  часто исчерпан на мобильных операторах с общим IP.
- Если все источники недоступны, в настройках появляется кнопка
  **«Открыть страницу релизов»** — APK можно скачать вручную.
- Старый способ через GitHub API остался запасным вариантом.
- Пресет **«Локальная сеть / AWG»** и проверка подключения из v1.0.3 сохранены.

## Установка

1. Скачайте `OpenCode-Client-by-inFernan-v1.0.4.apk`.
2. Разрешите установку из этого источника.
3. Обновление установится поверх v1.0.0 – v1.0.3.
